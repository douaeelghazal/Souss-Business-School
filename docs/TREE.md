## File Organization Benefits

✅ **Clear Separation**: Backend code separate from frontend assets  
✅ **Easy Scaling**: Static files can be served from CDN or separate server  
✅ **Production Ready**: Database in `data/` folder, separate from code  
✅ **Maintainable**: Scripts and docs are centralized  
✅ **Version Control**: .gitignore properly configured for each folder  
✅ **Development**: Everything in one place but logically organized  

## Quick Commands

### From Root Directory

```bash
# Activate virtual environment
.\.venv\Scripts\Activate.ps1

# Run setup (first time)
.\scripts\setup.ps1

# Start server
.\scripts\runserver.ps1

# Or manual
cd backend
python manage.py runserver
```

### From Backend Directory

```bash
# Apply migrations
python manage.py migrate

# Create superuser
python manage.py createsuperuser

# Collect static files (production)
python manage.py collectstatic

# Create migrations for model changes
python manage.py makemigrations

# Run tests
python manage.py test
```

## Environment Files

- `.env.example` - Template for environment variables (COMMIT THIS)
- `.env` - Local environment variables (NEVER COMMIT)
- `.gitignore` - Git ignore rules (COMMIT THIS)

## Static Files & Media Workflow

### Development
1. Place files in `backend/playground/static/` (CSS, JS, images)
2. Place uploads in `frontend/media/`
3. Django serves them automatically

### Production
1. Run `python manage.py collectstatic`
2. Files gather to `frontend/staticfiles/`
3. Web server (nginx) serves from there
4. Can be uploaded to CDN

## Database Location

**Development**: `backend/data/db.sqlite3`

To move/backup:
```bash
# Backup
Copy-Item backend/data/db.sqlite3 backend/data/db.sqlite3.backup

# Create new
Remove-Item backend/data/db.sqlite3
python manage.py migrate
```
