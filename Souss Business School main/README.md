# 🏫 Souss Massa Business School Website

## 📋 Project Overview

This project is a **dynamic website** built with **Django**, designed to showcase the **Souss Massa Business School**. The platform provides comprehensive information about the school, its academic programs, and its mission, targeting prospective students, faculty members, and partners.

A key feature is the **admin dashboard** 🛠️, allowing authorized users to **add or update news, programs, and other website content easily without modifying the codebase**, ensuring smooth content management.

---

## ✨ Key Features

- 📄 **Informational Pages**  
  Detailed content about the school’s history, vision, and offered academic programs.

- 📰 **News and Events Section**  
  Regularly updated announcements to keep users informed about the latest happenings.

- 📱 **Responsive Design**  
  Optimized user experience across desktops, tablets, and smartphones.

- 🛠️ **Admin Dashboard**  
  User-friendly backend interface enabling admins to manage news, programs, and media easily — no code changes required.

- 🖼️ **Media Integration**  
  Supports images and documents to enrich the website’s content.

- 💻 **JavaScript Enhancements**  
  Interactive elements and advanced features already integrated for smooth navigation and dynamic content.

- 🔐 **User Authentication & Role-Based Access Control**  
  Secure admin dashboard with user login and permission levels.

- 🔎 **Search Functionality**  
  Implemented search for programs, news, and datasets for better usability.
